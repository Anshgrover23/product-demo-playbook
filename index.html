The pipeline · 8 steps

Copy a prompt. Paste it to your agent.

01 · Script

Write the story first

45 to 60 seconds, ~6 scenes, one claim per scene: problem, drop, magic, interaction, proof, brand. Interactions on a 0.6s grid (that's 100 BPM, so the music locks to it later, free). Real data only: real items, printed prices, totals that reconcile.

Prompt · paste into your agent
Read .claude/skills/product-demo (start with SKILL.md and 01-script.md). Write the scene table and voiceover script for a ~50s demo of the app in this repo. One claim per scene, real fixture data, interactions on a 0.6s grid.
02 + 03 · Composition

Your real UI, on one clock

Vendor your actual components into a static bundle, then author the film as one React tree: a pure function of a clock T, with a synchronous seek contract. Nothing fades. Everything stamps, slides, rips, or snaps.

Prompt
Follow 02-standalone-ui.md and 03-composition.md: vendor this repo's UI components into demo/ds/ so they render from a static folder, then build the composition with an OM_SCENES cue table and a synchronous seek event. Motion rule: nothing fades.
04 · Record

Frame-perfect, never screen-recorded

Screen recording inherits every dropped frame; that stutter can't be edited out. The renderer seeks to each timestamp and screenshots it: 3,260 deterministic PNGs into visually lossless H.264. CSS animations get pinned to the clock (a spinner once ran 11× too fast without this).

Prompt
Follow 04-record.md using templates/record.mjs: render the composition frame-by-frame (smoke test first), pin CSS animations to the seek clock, and encode two 1440p60 masters, captions burned and clean.
05 · Captions + VO

Captions from the source of truth

The composition already knows every line and time; SRT/VTT are projections, never transcriptions. The VO script ships with per-line timecodes and sync notes ("'Show it.' lands on the squash-on-impact frame"), ready for your voice tool.

Prompt
Follow 05-captions-vo.md: project the composition's caption table into SRT and VTT sidecars, and write the timecoded voiceover script with sync notes for an AI voice tool.
06 · Sound

The demo scores itself

Ten sparse cues in a JSON file the composition owns, each with a measured hit offset (AI sound effects pad ~0.3s of silence before the impact) and a true peak level (they're mastered quiet; the mixer normalizes). One cue file, two players: live browser preview and the ffmpeg export mixer. They can never disagree.

Prompt
Follow 06-sound.md: write sfx-cues.json for this demo (max ~10 cues, one per story turn, each with a why), measure every sound file's hit offset, wire the WebAudio preview player, and score the export with templates/mix-audio.mjs.
07 + 08 · Music + Ship

Carve, duck, start at the drop

Music at the grid's BPM, trimmed to its drop (nobody grants your video a 15-second build). EQ-notched at 250 Hz and 2.8 kHz so the voice pops through without pumping. Then: founder intro, one branded tape transition, stems into the editor, −14 LUFS out.

Prompt
Follow 07-music.md and 08-assemble.md: add the music bed with mix-audio.mjs (--bgm-start at the track's drop), then assemble intro + transition + stems and export a 1440p master plus a captioned X-ready 1080p cut.
