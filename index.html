02 — Pipeline

Eight steps, in order

Each step is a recipe file with a prompt you can paste to your agent verbatim. The clips are unedited output from the reference demo.

01

Script01-script.md

45–60 seconds, six scenes, one claim per scene: problem, drop, magic, interaction, proof, brand. Interactions sit on a 0.6-second grid — that is 100 BPM, and the music will lock to it unedited. Fixture data is real: real items, printed prices, totals that reconcile.

prompt
Read .claude/skills/product-demo (SKILL.md, then 01-script.md). Write the scene table and voiceover script for a ~50s demo of the app in this repo. One claim per scene, real fixture data, interactions on a 0.6s grid.
02–03

Composition02-standalone-ui.md · 03-composition.md

Vendor the app's actual components into a static bundle, then author the film as one React tree — a pure function of a clock T with a synchronous seek contract. The motion rule is absolute: nothing fades. Everything stamps, slides, rips, or snaps.

prompt
Follow 02-standalone-ui.md and 03-composition.md: vendor this repo's UI into demo/ds/ so it renders from a static folder, then build the composition with an OM_SCENES cue table and a synchronous seek event. Nothing fades.
04

Record04-record.md

Screen recording inherits every dropped frame; that stutter cannot be edited out. The renderer seeks to each timestamp and screenshots it — thousands of deterministic PNGs into visually lossless H.264. CSS animations are pinned to the clock; a spinner once ran eleven times too fast without this.

prompt
Follow 04-record.md with templates/record.mjs: smoke-test four frames, then render frame-by-frame with CSS animations pinned to the seek clock. Encode two 1440p60 masters, captions burned and clean.
05

Captions & voiceover05-captions-vo.md

The composition already knows every line and time; SRT and VTT are projections of that table, never transcriptions. The voiceover script carries per-line timecodes and frame-level sync notes, ready for a voice tool.

prompt
Follow 05-captions-vo.md: project the composition's caption table into SRT and VTT sidecars, and write the timecoded voiceover script with sync notes.
06

Sound06-sound.md

Ten sparse cues in a JSON file the composition owns, each with a measured hit offset — AI sound effects pad ~0.3s of silence before the impact — and a true peak level. One cue file feeds two players, the live browser preview and the export mixer, so they cannot disagree.

prompt
Follow 06-sound.md: write sfx-cues.json (≤10 cues, one per story turn, each with a why), measure every file's hit offset, wire the preview player, and score the export with templates/mix-audio.mjs.
07–08

Music & ship07-music.md · 08-assemble.md

Music at the grid's tempo, trimmed to its drop. EQ notches at 250 Hz and 2.8 kHz let the voice pop through without audible ducking. Then the founder intro, one branded transition, stems into the editor, −14 LUFS out — plus a captioned cut for platforms that autoplay muted.

prompt
Follow 07-music.md and 08-assemble.md: add the music bed with mix-audio.mjs (--bgm-start at the track's drop), assemble intro + transition + stems, and export a 1440p master plus a captioned 1080p cut.
03 — Contents

What ships

Not a SaaS and not a template store. One folder of instructions, decision rules, and working scripts. The skill encodes the judgment — nothing fades, honest data, never screen-record, no sound beats a forced sound — and the scripts do the labor.

skills/product-demo/

The skill

SKILL.md and eight recipe files: the full pipeline as agent instructions, with decision rules for entering at any step — no script yet, footage that stutters, sound that buries.

templates/

Working scripts

record.mjs, the deterministic Playwright frame renderer. mix-audio.mjs, the cue-driven ffmpeg mixer. sfx-cues.example.json, a real ten-cue score. Lifted from a shipped launch, not written for this page.

manual.html

The manual

Every number, command, and failure from shipping the reference demo: the worked example, a fifteen-entry troubleshooting log, the complete ffmpeg reference. Read it.
