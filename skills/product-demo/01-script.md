# Step 1: Script

Write the story before touching any tool. The script drives scene lengths, cue
times, and music tempo.

## Produce four artifacts

**1. A scene table**, name, duration, and the single claim per scene. Target
45-60s total across ~6 scenes with this arc:

| Beat | Purpose | Vouch reference |
| --- | --- | --- |
| problem | open on the pain | ColdOpen 6s |
| drop | the artifact enters the product | TheDrop 5.5s |
| magic | the product does the impossible part | MachineReads 8s |
| interaction | humans touch it | Witness 11s |
| proof | the numbers reconcile | AddsUp 12s |
| brand | stamp the name | TheStamp 11.8s |

One claim per scene. If a scene proves two things, split it.

**2. Voiceover lines, one per beat, each with a start timecode.** Short
declaratives, read deadpan. The strongest pattern: a claim, then two two-word
hammer blows, then the detail that proves you built it:

> "Vouch reads the paper itself. Every line. Every price. Even the ink that's
> barely there."

**3. A rhythmic grid.** Put repeated interactions (taps, claims) on a fixed
grid. 0.6s = exactly 100 BPM; music at that tempo later locks to the picture
for free.

**4. Air pockets.** Mark 1-2 deliberate silences (a beat before the key
landing; the final ~6s with no VO). The pauses make the loud moments loud.

## Sync notes

End the script with frame-level contracts, e.g.:

```
'Show it.' lands on the squash-on-impact frame (~0:09.3);
silence from 0:48.5 to end for the outro and music resolve.
```

## Honesty rule

Decide the fixture data now: real items, the printed prices, a total that
actually sums (Vouch: 8 items, $84.20, including a tax-split beat). Viewers
feel fake data even when they cannot articulate why.
